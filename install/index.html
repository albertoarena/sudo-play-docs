Install

Sudo Play is a menu bar app for macOS. The current release is 1.0.2.

Download and install

You need a Mac with Apple silicon, M1 or later, and the Spotify app or a browser. There is no Intel build yet.

  1. Download Sudo-Play-1.0.2-arm64.dmg (opens in a new tab) (148 MB) from the 1.0.2 release (opens in a new tab).
  2. Install. Open the DMG and drag Sudo Play to Applications.
  3. Open Sudo Play. macOS asks once whether to open an app downloaded from the internet. Click Open.

The first time you press Play, macOS asks whether Sudo Play may control Spotify. Click Allow, so it can start the playlist in the Spotify app.

Coming from an earlier version? Download the DMG and drag Sudo Play to Applications, then choose Replace. Your settings stay. The app does not update itself.

If every button in the window shows an error, see Troubleshooting.

Check the download

This step is optional. In Terminal, run:

shasum -a 256 ~/Downloads/Sudo-Play-1.0.2-arm64.dmg

It should print b40e25cd44002387ebcbe54707ad56636d16c7c0d1f649bbc862d31e5d875d0f.

Hear about new releases

On the app's GitHub page (opens in a new tab), choose Watch, then Custom, then Releases. Sudo Play does not check for updates itself, because the daily catalog download is its only network call.

Run it from source

You can also run Sudo Play on a Mac with PHP 8.4, Composer and Node 22 or later. The app's README has the steps, in Run it from source (opens in a new tab). A copy of the catalog ships with the app, so it has playlists to suggest from the first run, even offline.
